# Knowledge Retention Policy

## Executive Summary
Defines what is retained indefinitely (aggregated statistics, failure signatures, release decisions) versus what is subject to pruning (raw execution artifacts like full video recordings).

## Default Policy

| Data | Retention |
|---|---|
| Aggregated test statistics | Indefinite |
| Failure signatures | Indefinite |
| Raw traces/videos | 90 days (configurable) |
| Release decisions | Indefinite |
