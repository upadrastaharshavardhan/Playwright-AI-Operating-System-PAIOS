# Entities

## Executive Summary
Canonical node types in the Knowledge Graph.

| Entity | Description |
|---|---|
| Requirement | A functional/business requirement |
| Test | A Playwright test case |
| Execution | A single run of a test |
| Failure | A failed execution |
| RootCause | A diagnosed cause of one or more failures |
| Component | A code module or UI component |
| Team | An owning team |
| Release | A deployable version |
| Agent | A PAIOS agent that performed an action |
