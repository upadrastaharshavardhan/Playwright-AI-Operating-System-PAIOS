# Director Layer

## Executive Summary
Director agents own a single quality domain end-to-end (functional correctness, performance, security, accessibility) across the entire product surface, coordinating Department/Squad agents within their domain.

## Responsibilities
- Define domain-specific quality gates (e.g., the Performance Director sets P95 latency regression thresholds).
- Aggregate Squad-level results into a domain quality score, feeding [Release Intelligence](../12-release-intelligence/README.md).
