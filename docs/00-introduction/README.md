# 00 · Introduction

## Overview

This section introduces PAIOS: what it is, why it exists, the philosophy behind its design, and how it compares to existing test automation frameworks and emerging AI testing tools. Read this section first if you are new to the project.

## Purpose

To give every reader — engineer, architect, engineering leader, or enterprise evaluator — a shared, precise understanding of what PAIOS is before diving into subsystem-level architecture.
