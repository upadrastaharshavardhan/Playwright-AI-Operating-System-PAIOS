# Example: Multi-Team Memory Federation

## Scenario
Team A (Payments) experiences a regression whose failure signature matches an incident Team B (Checkout) diagnosed eight months prior in a shared library. [Failure Memory](../../docs/05-memory-engine/failure-memory.md) surfaces the match automatically via semantic similarity, saving hours of re-diagnosis.
